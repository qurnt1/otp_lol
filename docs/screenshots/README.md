# Product screenshots

The README and project presentation use these screenshots:

- [`portfolio-dashboard-demo.png`](../images/portfolio-dashboard-demo.png), current dashboard with three example skin splash arts, no connected account and automation disabled;
- [`portfolio-statistics-demo.jpg`](../images/portfolio-statistics-demo.jpg), provider choices with no account configured;
- [`portfolio-settings-demo.jpg`](../images/portfolio-settings-demo.jpg), current Advanced settings page.

They use a synthetic or disconnected League client and contain no real Riot ID. The dashboard was captured on 14 October 2026 from the current React/FastAPI full-stack E2E app; the screenshot uses fixed Garen, Lux and Ashe skin presets, with the official Data Dragon artwork served locally to the isolated browser. Statistics and Settings were captured on the same date from the current React/FastAPI browser E2E app. These screenshots document the interface, not a live League session or a packaged WebView2 build.

The archived `settings-web.png` capture is not used by the current website. The former `dashboard-web.png` was removed because it was byte-identical to the current `portfolio-dashboard-demo.png`. The old `statistics-web.png` capture was removed because it exposed a real Riot ID and region; do not restore or reuse public copies of it.
