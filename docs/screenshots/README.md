# Product screenshots

The README and project presentation use these screenshots:

- [`portfolio-dashboard-demo.png`](../images/portfolio-dashboard-demo.png), dashboard with example presets and the League client disconnected;
- [`portfolio-statistics-demo.jpg`](../images/portfolio-statistics-demo.jpg), provider choices with no account configured;
- [`portfolio-settings-demo.jpg`](../images/portfolio-settings-demo.jpg), current Advanced settings page.

They use a simulated or disconnected League client and contain no real Riot ID. The dashboard image is a committed Playwright layout snapshot; Statistics and Settings were captured on 14 October 2026 from the current React/FastAPI browser E2E app. These screenshots document the interface, not a live League session or a packaged WebView2 build.

The older `dashboard-web.png`, `settings-web.png` and `statistics-web.png` images belong to the marketing-site capture set. Do not use them for public product documentation without checking their account data and UI state first.
